## Данные и защита от утечки

Train — 214 кадров, 193 детекции, 32 предмета, из них 6 тяжёлых (40 аннотаций) и 26 лёгких (125). Val — 49 кадров, 57 детекций, 8 других предметов, из них 1 тяжёлый (4 аннотации) и 7 лёгких (45). Списки object_id, порядок и координаты детекций сверены с кэшами. Идентификатор предмета использован только для разбиения и анализа ошибок. Дополнительные детекции сохранены при подсчёте официальных компонентов.

A воспроизводит исходное поле take. Оба предшествующих обновления CSV заменяли отдельные поля. Масса в #17150 по-прежнему рассчитана по исходному геометрическому объёму и плотности материала, предсказанного прежним RF. На OOF использованы его групповые предсказания. Val воспроизведена отдельно на всех 57 детекциях RF по 32 train-предметам. Предсказания объёма на этих же детекциях сверены с volume_train32.cbm с максимальным расхождением менее 0,000000001 мл. Справочник плотностей организаторов и замороженный детектор общие для A и B.

B — StandardScaler и LogisticRegression с L2, C=1, class_weight=balanced, solver=lbfgs. Порог P(take=1)>0,5 зафиксирован до оценки. Входы: log1p объёма, log1p расчётной массы, масса/500, шесть вероятностей материала, признак solid и площадь проекции в м². В качестве признаков использованы только предсказания и наблюдаемая геометрия. Для обучения — только сопоставленные детекции. Вес каждого кадра внутри класса одинаков. Разметка материала нужна для восстановления лёгких голов на разрешённых обучающих объектах.

Внешние фолды по 8 предметов повторяют этапы 1 и 2. Для оцениваемых предметов использованы сохранённые OOF CatBoost-объёмы, DINO-вероятности получены лёгкой линейной головой по замороженным эмбеддингам. На каждой сопоставленной детекции победивший класс проверен по сохранённым результатам этапа 1. На val использованы head_train32.npz и volume_train32.cbm. Модель take обучена по 32 предметам. Голову head_all40.npz для этого этапа не использовали.

Внутренние CatBoost-модели не сохранены. Если обучать LR на строках из остальных внешних фолдов с их кэшированными CatBoost-предсказаниями, upstream-модели этих строк могли видеть оцениваемый предмет. Для строгого протокола объём при обучении LR взят из физической геометрии; при инференсе на OOF, val и test подан уточнённый объём CatBoost. Это различие распределений ограничивает интерпретацию результата. Для внутренних обучающих строк внешнего фолда RF-массы и DINO-вероятности пересчитаны только на предметах оставшихся внутренних групп. Настройки и порог по val не подбирались. Тяжёлые модели не переобучались.
